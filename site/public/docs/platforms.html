Platforms

The same state model is implemented in JavaScript and Swift. Shared vectors make behavioral differences visible.

JavaScript core

rixse provides the store, typed actions, validation, authored log, undo, wire format and viewport helpers. rixse-react provides React bindings. The core itself has no UI framework dependency.

Swift core

rixse-swift includes the core state and components implementation. The iOS Movies demo renders the same component state with SwiftUI; platform drawing is the renderer’s job.

Conformance vectors

Text and JSON vectors under conformance/ exercise shared core semantics such as action validation, viewport actions, layout, wire encoding and the Movies vocabulary. JavaScript and Swift read the same fixtures. They check that implementations agree on those defined behaviors; they do not claim that every platform renderer has identical pixels or every app-specific adapter is interchangeable.

cd packages/rixse-swift
swift run rixse-conformance-check

The executable runs each vector and exits non-zero when one differs. swift test also exercises the vector checks on supported toolchains.
