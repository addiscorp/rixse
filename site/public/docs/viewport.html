Viewport API

The viewport turns component definitions into state, a catalogue for the agent and a set of typed actions.

Create a viewport

createViewport({ components: ComponentSpec[], sources: Record<string, SourceDef> })
// returns { initial, actions, catalogue, rowsFor, components }

initial() returns { items: {}, order: [], selection: null }. catalogue() describes components and sources. rowsFor(item) runs the item’s query via its source. components is a map by kind.

Actions

Each action is dispatched through the store as store.dispatch({ type, payload }, author). The author is 'you' or 'agent'.

ActionPayload shapeEffect
view.show{ id, kind, title, query?, size?, ...componentParams, at?, target? }Adds or updates a component. Optional placement: at end/before/after/replace and target id. A replacement removes the target.
view.move{ id, at: 'end'|'before'|'after', target? }Moves an existing component in order.
view.resize{ id, size }Changes to a size supported by that kind.
view.remove{ id }Removes a component and its selection.
view.clear{}Resets viewport state.
select.set{ view, items }Sets selected values; items is a pipe-separated string.
select.clear{}Clears the current selection.

Runnable action example

From the repository root with the rixse workspace installed, this snippet exercises every viewport and selection action against the main implementation:

import { createStore, createViewport, defineComponent, defineSource } from 'rixse/ui';

const line = defineComponent('line', {
  describe: 'Yearly values', sizes: ['large', 'viewport'],
  source: 'movies',
  params: {
    label: { type: 'string', optional: true },
    x: { type: 'string' }, value: { type: 'string' }
  }
});
const movies = defineSource({
  describe: 'A local Movies source', query: 'ZQL',
  run: () => [{ title: 'Avatar', year: 2009, gross: 1 }]
});
const viewport = createViewport({ components: [line], sources: { movies } });
const store = createStore({ initial: viewport.initial(), actions: viewport.actions });
const dispatch = (type, payload) => store.dispatch({ type, payload }, 'you');

dispatch('view.show', { id: 'years', kind: 'line', title: 'By year',
  query: '{ Movie limit 100000 { title year gross } }',
  label: 'title', x: 'year', value: 'gross', size: 'large' });
dispatch('view.move', { id: 'years', at: 'end' });
dispatch('view.resize', { id: 'years', size: 'viewport' });
dispatch('select.set', { view: 'years', items: 'Avatar|Titanic' });
dispatch('select.clear', {});
dispatch('view.remove', { id: 'years' });
dispatch('view.clear', {});

These payloads follow the action definitions generated by createViewport in main. Each action is validated and either applied atomically or rejected with a readable reason.
